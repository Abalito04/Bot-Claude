# 🧠 Bot-Claude

Conversational AI chatbot powered by **Anthropic's Claude API** with a simple web interface.

## ✨ Features

- Conversational AI using Claude API (Anthropic)
- Context-aware multi-turn conversations
- Clean web chat interface
- Python/Flask backend

## 🛠️ Tech Stack

- **Python** · Flask
- **Anthropic Claude API**
- **HTML/CSS/JavaScript**

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Abalito04/Bot-Claude.git
cd Bot-Claude

# Install dependencies
pip install -r requirements.txt

# Set your Claude API key
export ANTHROPIC_API_KEY=your_api_key_here

# Run the app
python app.py
```
